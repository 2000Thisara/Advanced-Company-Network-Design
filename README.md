# Advanced Company Network Project (Cisco Packet Tracer) 🌐🔒
<br><br>

## 📜 Project Overview

This repository contains the complete design and configuration files for an **Advanced Company Network** implemented using **Cisco Packet Tracer**. The project follows a secure, scalable **Hierarchical Network Design**, incorporating advanced features such as Firewall Zoning, High Availability, Dynamic Routing, Voice over IP (VoIP), and Enterprise Wireless.
<br><br>

## 🚀 Key Implemented Technologies and Skills

This project demonstrates expertise across multiple networking domains:

| Category | Implemented Technology | Skill Demonstrated |
| :--- | :--- | :--- |
| **Security** | **Cisco ASA Firewall** | **Firewall Zones** (Inside, Outside, DMZ), **Inspection Policies (ACLs)**, **NAT** (Static/PAT). |
| **High Availability** | **HSRP** (Hot Standby Router Protocol) | Gateway redundancy for continuous network access. |
| | **LACP EtherChannel** | Link aggregation for bandwidth and link redundancy. |
| **Routing & Switching** | **OSPF** (Routing Protocol) | Dynamic path determination across distribution layer. |
| | **SVI / Router-on-a-Stick** | Efficient **Inter-VLAN Routing** on Layer 3 switches. |
| | **VLANs** (MGT, LAN, VoIP, Guest) | Network segmentation and traffic isolation. |
| **Layer 2 Security** | **STP PortFast & BPDUGuard** | Preventing Layer 2 loops and ensuring fast port activation. |
| **Services** | **Cisco WLC & LAPs** | Management of **Corporate, Guest, and Employee Wireless Networks**. |
| | **Cisco Voice Gateways & IP Phones** | Full **Telephony Service** (VoIP) implementation. |
| **Access Control** | **SSH & Standard ACL** | Secure remote device management with restricted access. |
| **WAN/Cloud** | **Default Static Route** | Connectivity simulation to **ISP** and **AWS Cloud Platform**. |
